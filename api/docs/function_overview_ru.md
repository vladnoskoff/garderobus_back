# Обзор функций бэкенда Smart Closet

Документ описывает ключевые функции и вспомогательные утилиты сервера Smart Closet. Материал структурирован по файлам и модулям, чтобы упростить поиск места для внесения изменений. Для каждой функции указаны назначение, основные параметры и важные детали реализации.

## `main.py`

| Функция | Описание |
| --- | --- |
| `read_root()` | Простейший health-check. Возвращает JSON `{ "message": "Smart Closet API is running!" }`, подтверждая, что приложение FastAPI поднято. |

## `database.py`

| Функция | Описание |
| --- | --- |
| `get_db()` | Провайдер подключения SQLAlchemy. Создаёт сессию `SessionLocal`, отдаёт её через `yield`, а после завершения запроса закрывает соединение. Используется как зависимость `Depends` в роутерах. |

## `openai_client.py`

| Функция | Описание |
| --- | --- |
| `_build_http_client()` | Настраивает `httpx.Client` с SOCKS-прокси, если он включён в `settings`. Возвращает `None`, если прокси не нужен. |
| `get_openai_client()` | Кешированный (через `lru_cache`) конструктор клиента OpenAI. Проверяет наличие корректного API-ключа, опционально подключает HTTP-клиент с прокси и выдаёт экземпляр `OpenAI`. |
| `is_proxy_active()` | Флаг, сигнализирующий, что прокси включён и задан URL. Используется для диагностики. |

## `models.py`

### `User`

* Хранит учетные данные и настройки пользователя.
* Связан с `WardrobeLocation` (атрибут `locations`).

### `Clothes`

* Описывает предмет гардероба.
* Связан с `ClothesMetadata` (атрибут `metadata_entry`) и `WardrobeLocation` (атрибут `location`).
* Вспомогательные методы и свойства:
  * `_metadata_dict()` — безопасно приводит поле `ai_metadata` к `dict`.
  * `temperature_min` / `temperature_max` — вычисляют допустимый температурный диапазон по полю `temp_c_range` из `ai_metadata`.
  * Свойство `ai_metadata` перегружено: при чтении возвращает словарь, при записи гарантирует синхронизацию с записью `ClothesMetadata`.

### Прочие модели

* `Weather` — погодные снимки.
* `Outfit` — сохранённые образы (связь с пользователем и погодой, набор `clothing_ids`).
* `WearHistory` — история носки вещей.
* `ClothesMetadata` — JSON-поле с расширенными данными по одежде, связанное один-к-одному с `Clothes`.
* `WardrobeLocation` — отдельные гардеробы/адреса пользователя, с координатами.

## `routes/users.py`

| Функция | Описание |
| --- | --- |
| `_normalize_gender(value)` | Приводит произвольный ввод пола к `male`, `female` или чистой строке, отфильтровывая пустые значения. |
| `create_access_token(data)` | Генерирует JWT-токен со сроком жизни 1 день. |
| `register(user, db)` | Создаёт нового пользователя: проверяет email на уникальность, хэширует пароль, нормализует пол. |
| `login(user, db)` | Проверяет email и пароль, выдаёт access token и ID. |
| `delete_user(user_id, db)` | Удаляет пользователя по ID. |
| `get_user(user_id, db)` | Возвращает модель пользователя или 404. |
| `update_user(user_id, updates, db)` | Обновляет имя, email, пароль, локацию и пол при наличии данных. |
| `update_style(user_id, style, db)` | Сохраняет предпочтительный стиль пользователя (пока поле `style_preference` не объявлено в модели, но обновляется динамически). |
| `update_keys(user_id, keys, db)` | Обновляет сохранённые API-ключи (OpenAI и OpenWeather). |

## `routes/clothes.py`

### Работа со списками

| Функция | Описание |
| --- | --- |
| `get_user_clothes(user_id, location_id, db)` | Возвращает список одежды пользователя, опционально фильтруя по гардеробной локации (использует `ensure_location_for_user`). |
| `get_all_clothes(db)` | Возвращает всю одежду из базы (без фильтров). |
| `get_clothes(clothes_id, db)` | Ищет вещь по ID или отдаёт 404. |
| `delete_clothes(clothes_id, db)` | Удаляет вещь и возвращает подтверждение. |

### AI-пайплайн для одежды

| Функция | Описание |
| --- | --- |
| `_build_ai_messages(image_payload, is_base64)` | Формирует сообщения для chat-completion: system-инструкция + пользовательский запрос с изображением (URL или data URI). |
| `_call_ai_for_insights(messages)` | Отправляет запрос в `gpt-4o-mini` с принудительной JSON-схемой. Валидирует, что ответ не пуст. |
| `_analyze_image_bytes(image_bytes)` | Кодирует изображение в Base64, вызывает `_call_ai_for_insights`, валидирует ответ схемой `ClothesInsights`. |
| `_insights_to_autofill(insights)` | Переводит `ClothesInsights` в структуру `ClothesAutoFill`: вытягивает основные поля, описания, температурные диапазоны. |
| `autofill_clothes_fields(file)` | Асинхронный эндпоинт, принимает изображение, возвращает автозаполненные поля для карточки одежды. |

### Загрузка одежды

| Функция | Описание |
| --- | --- |
| `add_clothes(...)` | Основной эндпоинт добавления одежды. Читает изображение, опционально автозаполняет поля через AI, сохраняет файл в директорию пользователя, обрабатывает температурные диапазоны и создаёт запись `Clothes`. |

## `routes/clothes_update.py`

| Функция | Описание |
| --- | --- |
| `get_user_clothes(user_id, location_id, db)` | Альтернативная версия списка одежды (дублирует поведение из `clothes.py`). |
| `describe_image_from_url(image_url)` | Использует `gpt-4o` для текстового описания одежды по ссылке. Возвращает короткий абзац. |
| `add_clothes(...)` | Альтернативный загрузчик: отправляет изображение в Uploadcare, сохраняет URL и минимальные текстовые поля. |
| `get_all_clothes(db)` / `get_clothes(clothes_id, db)` / `delete_clothes(clothes_id, db)` | CRUD-операции, аналогичные версиям из `clothes.py`, но при удалении дополнительно чистят ресурс в Uploadcare. |

## `routes/ai_recommendation.py`

### Вспомогательные функции

| Функция | Описание |
| --- | --- |
| `_safe_metadata(item)` | Безопасно преобразует `ai_metadata` одежды в словарь. |
| `_extract_temp_range(item)` | Возвращает `(min_temp, max_temp)` из метаданных вещи. |
| `_temperature_score(temperature, temp_range)` | Числовая оценка, насколько текущая температура отличается от допустимой для вещи (0 — идеально). |
| `_filter_by_season(clothes, weather)` | Фильтрует одежду по сезонным признакам, исходя из температуры погоды. |
| `_select_outfit(clothes, weather)` | Собирает до четырёх вещей с минимальным температурным штрафом и без повторов категорий. Дополняет сезонными вариантами, если не хватает позиций. |
| `_mannequin_gender_instruction(gender)` | Возвращает инструкцию по полу манекена для промпта. |
| `_build_mannequin_prompt(items, weather, gender)` | Создаёт подробный текстовый промпт для генерации изображения манекена. |
| `_save_mannequin_image(image_b64, user_id, request)` | Сохраняет base64-изображение манекена в файловую систему и возвращает публичный URL с учётом базового префикса приложения. |

### Эндпоинты

| Функция | Описание |
| --- | --- |
| `ai_recommendation(user_id, db)` | Анализирует последние 10 нарядов пользователя, формирует систематизированный запрос к `gpt-4o-mini` и возвращает рекомендации стилиста с учётом погоды. |
| `generate_mannequin(user_id, location_id, db)` | Подбирает одежду под текущую погоду, генерирует промпт и создаёт изображение манекена через `gpt-image-1`, сохраняет результат и возвращает ссылку + использованные вещи. |

## `routes/outfits.py`

| Функция | Описание |
| --- | --- |
| `get_outfit(user_id, location_id, db)` | Получает координаты пользователя (либо по профилю, либо по выбранной локации), запрашивает погоду через `get_weather_by_coordinates`, определяет сезон по температуре, подбирает вещи по категориям и сохраняет получившийся наряд в таблицу `Outfit`. |

## `routes/weather.py`

| Функция | Описание |
| --- | --- |
| `get_weather_by_coordinates(lat, lon, db, api_key)` | Запрашивает текущую погоду и трёхдневный прогноз в OpenWeather по координатам, сохраняет текущие условия в БД и возвращает агрегированный ответ с прогнозом. |
| `get_weather_for_user(user_id, location_id, db)` | Извлекает координаты пользователя (по профилю или локации) и вызывает `get_weather_by_coordinates` с его API-ключом. |

## `routes/wardrobe_analytics.py`

| Функция | Описание |
| --- | --- |
| `most_worn_clothes(user_id, db)` | Возвращает топ-5 вещей с наибольшим количеством записей в `WearHistory` для пользователя. |
| `least_worn_clothes(user_id, db)` | Находит вещи, которые не надевались более 30 дней: исключает позиции с записями `WearHistory` новее пороговой даты. |

## `routes/esp_display.py`

| Функция | Описание |
| --- | --- |
| `send_outfit_to_display(user_id)` | Запрашивает визуальную рекомендацию `/ai/visual-recommendation/{user_id}` и отправляет полученный URL изображения на ESP32-дисплей. |

## `routes/location_utils.py`

| Функция | Описание |
| --- | --- |
| `ensure_location_for_user(db, user_id, location_id)` | Проверяет, что локация принадлежит пользователю. Выбрасывает 404 при несоответствии. |
| `resolve_location_and_coordinates(db, user, location_id)` | Возвращает выбранную локацию и координаты: берёт либо координаты профиля (`user.location`), либо координаты конкретной локации. |

## `routes/locations.py`

| Функция | Описание |
| --- | --- |
| `list_locations(user_id, db)` | Возвращает список гардеробных локаций пользователя в порядке создания. |
