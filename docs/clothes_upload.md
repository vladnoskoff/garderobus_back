# Загрузка одежды: множественные фото и авторазбиение

Этот документ описывает поведение эндпойнта `POST /clothes/` после добавления флагов группировки изображений.

## Базовый сценарий
- Если **`split_into_items` = false** (по умолчанию), все загруженные файлы образуют **одну** вещь.
- Первый файл становится обложкой, остальные попадают в галерею.
- Пустые файлы отбрасываются; при отсутствии валидных файлов вернётся 400.

## Авторазбиение на вещи
- Если **`split_into_items` = true** и загружено более 1 файла, включается группировка.
- Параметр **`images_per_item`** задаёт, сколько подряд идущих файлов составляют одну вещь.
  - Значение должно быть >= 1, иначе вернётся 400.
  - Файлы режутся «слева направо»: каждая пачка создаёт отдельную вещь.
  - Если файлов не хватает до полного блока, оставшиеся всё равно формируют последнюю вещь.

Пример: загружено 6 фото, `images_per_item=2` — получится 3 вещи с парами «основной вид + бирка». Если `images_per_item=3` — будет 2 вещи: первые три фото и оставшиеся три.

## Автозаполнение полей
- Поля `name`, `category`, `season`, `color` обязательны. Если они не переданы (или включён `auto_fill`), они дополняются анализом изображения.
- Анализ берёт **первый файл каждой группы** и делает:
  - AI-инсайты по изображению (_model: `gpt-4o-mini`_) на языке `language_code` (`ru` по умолчанию);
  - слияние автогенерации и ручного ввода по принципу «ручное важнее, если `auto_fill=false`»;
  - перенос температур из `ai_metadata.temp_c_range` и из полей `temperature_min/max` в единый диапазон.
- При передаче `ai_metadata` строкой JSON она используется как исходный payload для вещи.

## Сохранение изображений
- Для каждой созданной вещи файлы пишутся в каталог `CLOTHES_IMAGE_DIR/{user_id}/{location}/{clothes_id}/` с уникальными именами.
- Первое изображение группы становится `image_url` вещи; остальные добавляются как `ClothesImage` с флагом `is_primary=false`.
- Параметр `label_image_index` (1-based) позволяет отметить фото бирки внутри каждой группы. Если индекс указан и попадает в диапазон
  размера группы, это изображение сохраняется в отдельное поле `label_image_url` и получает флаг `is_label=true` в галерее. При
  перемещении вещи между локациями ссылка бирки обновляется вместе с остальными изображениями.

## Инвалидация кэша
- После успешного создания вещи (или нескольких вещей) очищаются кэши одежды и истории образов пользователя.
