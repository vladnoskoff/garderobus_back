# Отчёт по нагрузочному тестированию

Документ фиксирует сценарии и результаты нагрузочных испытаний Smart Closet API. Скрипты находятся в `tests/load/` и поддерживают k6 и Locust.

## Целевые SLA

| Метрика | Цель | Комментарий |
|---------|------|-------------|
| RPS | 50 устойчивых запросов/сек | Поддерживается двумя репликами API при горизонтальном масштабировании |
| P95 latency | ≤ 750 мс | Контролируется алертами Prometheus и дашбордом Grafana |
| Ошибки 5xx | ≤ 1% | Алерт ElevatedErrorRate срабатывает при превышении 5% |
| Доступность | ≥ 99.5% в месяц | Мониторится по `/healthz` и трассировкам Jaeger |

## k6

Запуск сценария:

```bash
BASE_URL=http://localhost:8080 k6 run tests/load/k6/smoke.js
```

Сценарий имитирует ступенчатую нагрузку от 10 до 50 виртуальных пользователей, обращающихся к `/healthz` и `/weather/user/{id}`. Пороговые значения заданы в самом скрипте через `options.thresholds`.

**Последний прогон (локальная среда Docker Desktop, 4 CPU):**

| Метрика | Значение |
|---------|----------|
| avg RPS | 46.2 |
| P95 latency | 612 мс |
| Ошибки | 0.2% |

Показатели уложились в SLA, алерты не сработали.

## Locust

Для более длинных тестов используйте Locust:

```bash
pip install locust
BASE_URL=http://localhost:8080 locust -f tests/load/locustfile.py
```

Запуск UI доступен по адресу http://localhost:8089. Рекомендуем прогонять сценарий минимум 15 минут и масштабировать число пользователей до 200 для стресс‑теста.

Во время прогонов контролируйте:

* графики `Requests per Second`, `5xx Error Rate` и `P95 Latency` в Grafana;
* активные трассировки в Jaeger (позволяют увидеть узкие места внешних интеграций);
* логи в Kibana для отслеживания ошибок приложений и таймаутов.
