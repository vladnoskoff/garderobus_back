# Настройка поддержки языков в базе данных

Чтобы приложения могли хранить предпочтения пользователей по языку интерфейса, в таблице `users` должна быть колонка `language_preference`. Ниже приведены примерные SQL-команды для PostgreSQL. При необходимости адаптируйте их под используемую СУБД.

```sql
-- Добавляем колонку для хранения выбранного языка
ALTER TABLE users
    ADD COLUMN IF NOT EXISTS language_preference VARCHAR(10) DEFAULT 'ru';

-- Обновляем существующие записи, чтобы у всех был установлен русский язык по умолчанию
UPDATE users
SET language_preference = 'ru'
WHERE language_preference IS NULL OR language_preference = '';
```

Если на стороне API используется валидация входных данных, убедитесь, что значение `language_preference` допускает коды `ru` и `en`. При необходимости расширения списка языков просто добавьте новые коды ISO 639-1 и обновите ограничения.
