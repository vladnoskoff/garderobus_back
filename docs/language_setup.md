# Настройка поддержки языков в базе данных

Чтобы мобильное приложение могло сохранять выбор языка интерфейса и передавать его в API, в таблице `users` должна существовать колонка `language_preference`. Ниже приведены примерные SQL-команды для PostgreSQL (адаптируйте под свою СУБД при необходимости).

```sql
-- Добавляем колонку для хранения выбранного языка (русский — значение по умолчанию)
ALTER TABLE users
    ADD COLUMN IF NOT EXISTS language_preference VARCHAR(10) DEFAULT 'ru';

-- Обновляем существующие записи, чтобы у всех пользователей был установлен русский язык по умолчанию
UPDATE users
SET language_preference = 'ru'
WHERE language_preference IS NULL OR language_preference = '';
```

API принимает двухсимвольные коды языков ISO 639-1. На текущий момент поддерживаются `ru` и `en`. При расширении списка языков добавьте новые коды в колонку и обновите валидацию на стороне API.
